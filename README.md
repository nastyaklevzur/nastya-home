# Дом Насти — домашний экран проектора

Android TV-лаунчер для проектора Formovie (Android 9, armeabi-v7a, без Google-сервисов).
При включении показывает короткую заставку с приветствием, затем главный экран: погода и часы,
лента новостей Калининграда, «Топ-10 рекомендаций кино» с метками просмотра, онлайн-камеры
Калининградской области и ярлыки приложений. Всё помещается на одном экране без прокрутки (960×540 dp).

## Что на экране

* **Заставка «Тёплый рассвет»** — 5 секунд анимации View (пятна света, появление текста,
  пульсирующее сердечко), пропускается любой кнопкой пульта. Показывается при холодном старте и когда
  лаунчер не видели больше 10 минут (например, после фильма); если переключаться между приложениями
  чаще — не мешает. Фон каждый раз новый — свежий снимок из космоса (`SplashBackdrops.kt`): Земля
  с GOES-East/West (NOAA), «Электро-Л» (Роскосмос) и Himawari-9, Солнце с SDO и коронографа SOHO,
  ночью — камеры полярного сияния в Тромсё и Соданкюля. Следующий снимок скачивается заранее.
  Живого видео с МКС вне YouTube не существует (проверено 2 ноября 2026).
* **Погода в Калининграде** — `api.met.no` (норвежский Yr, без ключа), запасной источник `7timer.info`.
  Open-Meteo и wttr.in с проектора недоступны (провайдер режет TLS). Обновляется раз в 30 минут.
* **Новости** — RSS «Нового Калининграда» (`newkaliningrad.ru/news/rss.xml`), 6 заголовков сменяются
  каждые 7 секунд. Список лент — `NewsRepository.FEEDS`; там же закомментированы проверенные запасные
  («Клопс», kgd.ru).
* **Кино** — ряд из десяти карточек, собранный из пула (см. ниже). OK открывает экран «О фильме» (сюжет, рейтинги, награды, отзывы),
  там кнопка «Смотреть» запускает карточку фильма в LAMPA (по `tmdb_id`) и ставит метку «Начат просмотр». Кнопка **Menu** на карточке: «О фильме», «Закрепить» (до трёх, первые в ряду, значок 📌),
  «В избранное», «👍 Нравится» (сигнал вкуса, фильм остаётся), «👎 Не нравится» (убирает), «Просмотрен» (с вопросом «Понравился?»), «Не буду смотреть». Убранная карточка исчезает сразу, на её место встаёт
  следующий фильм из пула, 6 секунд кнопка Назад возвращает её. Кнопка ♥ у заголовка открывает «Избранное» и «Скрытые».
  На карточках слева сверху значки: 🏆 лауреат крупной премии, 📌 закреплён, ♥ в избранном, 👍 нравится; в «О фильме» — рейтинги, награды, «почему тебе»
  и мнение критиков.
* **Онлайн-камеры** — ряд плиток из `cams.json`, OK открывает встроенный плеер (Media3 ExoPlayer, HLS).
  Если поток не идёт, плеер предлагает «Ещё раз» или «Открыть в VLC». В ряду: Зеленоградск, паром
  Балтийска, Музей Мирового океана (две камеры), зверушки для Кузи — панды Диндин и Катюша
  (Московский зоопарк), волки Международного центра волков (Миннесота, две камеры; эфир с 18:00 по Калининграду, до этого плеер показывает, во сколько включится),
  жирафы Greenville Zoo (загон и стойло), львы, тигр, гориллы, орангутаны, слоны и зебры с жирафом
  Московского зоопарка, фламинго Zoo Miami, водопой на реке Чобе и ламантины во Флориде — затем фонтан
  Треви, Санторини, Таймс-сквер, Ниагара, Эльбрус, Байкал с горы Соболиной, Териберка. Ещё 52 проверенные
  камеры лежат в файле скрытыми.
* **Приложения** — LAMPA, SmartTube, Кинопоиск, RuStore, VLC, Настройки (только установленные)
  и кнопка «Обновить» (перекачивает подборку, камеры, погоду и новости).

## Данные в репозитории

Приложение при запуске (и раз в час) скачивает `movies.json` и `cams.json`:

1. `https://raw.githubusercontent.com/nastyaklevzur/nastya-home/main/<файл>`
2. запасной адрес: `https://cdn.jsdelivr.net/gh/nastyaklevzur/nastya-home@main/<файл>`

Удачно скачанный файл кэшируется на устройстве; если сети нет, показывается кэш, а если и его нет —
копия, вшитая в APK при сборке (`movies.json`, `cams.json`, `posters/`, `cams/`).
Картинки с относительными путями берутся с того же адреса, откуда удалось скачать JSON.

### Формат `movies.json` (v2 — пул)

С версии 2 файл содержит не десятку, а **пул из 30–40 фильмов**, отсортированный по рангу. Ряд «топ-10» собирает сам проектор
(`RowBuilder.kt`): закреплённые Настей фильмы идут первыми, в ряду всегда три новинки, просмотренные и убранные не возвращаются,
остальные карточки держат свои места, пока пул тот же; новый пул раскладывается по рангу заново. Старое приложение (v1) просто показывает первые десять.

```json
{
  "version": 2,
  "title": "Топ-10 рекомендаций кино",
  "updated": "2026-11-02",
  "movies": [
    {
      "tmdb_id": 13, "imdb_id": "tt0109830", "kinopoisk_id": 448, "wikidata": "Q134773",
      "title": "Форрест Гамп", "original_title": "Forrest Gump", "year": 1994,
      "rating": 8.8, "imdb_rating": 8.8, "imdb_votes": 2550229,
      "genres": ["драма", "комедия"], "runtime": 142, "country": "США", "director": "Роберт Земекис",
      "note": "Тёплая история, после которой хочется обнять",
      "why_you": "Тебе понравилась «Амели» — тут та же тёплая интонация",
      "critics": "Metacritic 82. «Редкий случай, когда сентиментальность работает»",
      "awards": [{"award": "oscar", "result": "won", "count": 6, "label": "6 «Оскаров», в том числе лучший фильм"}],
      "award_badge": "🏆 Оскар",
      "premiere": "1994-06-23", "is_new": false,
      "rank": 1, "added": "2026-11-02",
      "poster": "posters/forrest_gump.jpg"
    }
  ]
}
```

Обязательные поля: `tmdb_id`, `title`, `year`, `rating`, `note` (до 48 символов), `poster`, `rank`. Остальное необязательно:
`why_you` (до 90) и `critics` (до 160) пишет Claude, `overview` — начало сюжета из русской Википедии (до 420 символов), `reviews` — до трёх отзывов зрителей Кинопоиска
(только при наличии `KINOPOISK_KEY`), `award_badge` показывается на карточке, `is_new` — новинка
(премьера за последние 18 месяцев и прошло ≥ 75 дней, то есть цифровой релиз состоялся). `rating` = рейтинг IMDb.

### `state.json` — что сделала Настя

Проектор ведёт файл состояния и отправляет его в этот репозиторий через GitHub API (нужен токен, см. «Сборка»):
закреплённые (`pinned`), избранное (`favorites`), убранные (`removed` с `reason: watched|skip` и оценкой `liked`),
«начат просмотр» (`started`). У каждой записи — снимок карточки (`snap`), чтобы экран «Избранное» работал и после того, как фильм
выбыл из пула, и номер действия `seq`. Единственный писатель файла — проектор; Mac только читает.
На чистой установке приложение само забирает `state.json` из репозитория.

### Формат `cams.json`

```json
{
  "title": "Онлайн-камеры",
  "cams": [
    { "id": "zelenogradsk-promenade", "title": "Зеленоградск", "subtitle": "променад и «Глаз Балтики»",
      "type": "hls", "url": "https://mmx.kgd.ru/traffic/trafcam6zel.m3u8", "referer": "https://kgd.ru/",
      "preview": "cams/zelenogradsk.jpg" },
    { "id": "baltiysk-ferry", "title": "Паром Балтийска", "type": "ipeye",
      "dev": "8ea53f0b98b54202a87f37c96065dcdb", "server": "sr-171-25-232-163.ipeye.ru",
      "preview": "https://api.ipeye.ru/v1/stream/poster/1/8ea53f0b98b54202a87f37c96065dcdb/img.jpeg",
      "preview_fallback": "cams/baltiysk.jpg" },
    { "id": "svetlogorsk-coast", "hidden": true, "title": "Светлогорск", "type": "ivideon",
      "server": "100-JSKX0DSQBGgXXPmmXixp4B", "cam": "393216" }
  ]
}
```

* `type: "hls"` — прямой адрес `.m3u8`; `referer` добавляется к запросам (kgd.ru без него отдаёт 403).
* `type: "ipeye"` — камеры IPEYE: `dev` (идентификатор) и `server` (запасной). Актуальный сервер
  приложение узнаёт у `ipeye.ru/webs/stream_info.php?devid=…` при каждом запуске.
* `type: "ivideon"` — публичные камеры Ivideon: `server` и `cam`; плеер идёт по редиректу на CDN
  (ответ приходит через 10–15 секунд, это нормально).
* `type: "skyline"` — Skyline Webcams: `page` (страница камеры), токен берётся из HTML перед запуском
  и живёт пару минут; при обрыве плеер сам запрашивает новый.
* `type: "earthcam"` — EarthCam: `url` плейлиста `videos-N.earthcam.com/fecnetwork/<ID>.flv/playlist.m3u8`,
  браузерный User-Agent и Referer подставляются автоматически.
* `type: "rtspme"` — камеры на rtsp.me / rtsp.ru: `cam` (id embed), `server` (`rtsp.me` или `rtsp.ru`);
  двухшаговый токен, адрес живёт около часа.
* `type: "rostelecom"` — публичные камеры Ростелекома: `cam` = токен из ссылки `lk-b2b.camera.rt.ru/sl/<токен>`.
* `type: "page"` — универсальный: первая ссылка на `.m3u8` в HTML страницы `page` (камеры Кировска на 123streaming.ru).
* `type: "ipcamlive"` — плеер ipcamlive.com: `cam` = alias из ссылки `g1.ipcamlive.com/player/player.php?alias=…`;
  сервер и идентификатор потока приложение спрашивает у `getcamerastreamstate.php` перед запуском
  (`streams_timeshift/<id>/stream.m3u8`, там же лежит живой кадр `snapshot.jpg`).
* `type: "moszoo"` — трансляции Московского зоопарка (zoo.mos.ru): `page` — страница вольера, `cam` — `data-id`
  виджета на ней (`panda4`, `capybara4`…). Живой эфир идёт только в часы работы зоопарка; в остальное время
  сервер отвечает 404, и плеер берёт из того же виджета «повтор дневного эфира». Манула нет ни живьём, ни в повторе.
* `preview` — живой кадр (абсолютный адрес) или картинка из репозитория; `preview_fallback` — статичная
  картинка, если живой кадр не загрузился. `hidden: true` — камера в списке, но не показывается;
  так в файле лежат скрытыми ещё 52 проверенные камеры: животные (Московский зоопарк — две запасные камеры панд, капибары,
  еноты, гигантские выдры, сурикаты, белый медведь, леопард, пума, рыси, медоеды, бегемот, журавли, малайские
  медведи; EarthCam — сурикаты Zoo Miami, подводная камера ламантинов), Калининградская область (закат в Зеленоградске,
  Светлогорск ×3, Балтийская коса, Дом Советов, ул. 9 Апреля), Италия и Греция (Сан-Марко, Колизей,
  Позитано, Капри, Миконос, Акрополь, Этна, Стромболи), Европа и мир (Прага, Краков, Сплит, Мальдивы,
  Тенерифе, Стена Плача, Исландия ×2, Сидней, Шанхай, Патагония, Эбби-Роуд, Дублин, Новый Орлеан),
  Россия (Эльбрус ×2, Байкал «Пологая», Северо-Курильск, пляж Кольского залива, Хибины, Грозный-Сити).
  Чтобы включить камеру, уберите `hidden` и запушьте файл — пересборка не нужна.

Калининградские камеры и по одной из каждой новой группы проверены на проекторе 2 ноября 2026,
остальные — с Mac. Камеры животных найдены вечером 2 ноября: с Mac и проектора проверены повторы

и оба вольера сурикатов спрятаны — в кадре зверей почти не бывает (панд тоже прятали, но по просьбе пользователя вернули); включены вольеры, где зверей видно (львы, тигр,

`cams-city.md`, `cams-world-famous.md`, `cams-russia.md`, `cams-world-space.md`, `cams-animals.md`).

поэтому эти корневые сертификаты добавлены в приложение (`res/raw`, `network_security_config.xml`).

## Обновление подборки (ежедневная задача на Mac)

Подборку ведёт запланированная задача Claude Code `nastya-daily-movies` (каждый день в 09:08, пока на Mac открыт Claude).
В будни — лёгкий прогон: прочитать `state.json`, убрать из пула просмотренное и отвергнутое, долить замену, пересчитать порядок
с учётом оценок. По понедельникам — большой: свежие новинки, рецензии, премии, профиль вкусов (`taste.json`), замена до трети пула.
Правила отбора и ранжирования — в [docs/prd-recsys-v2.md](docs/prd-recsys-v2.md), §8.

Инструмент — `scripts/pool.py` (ключи не нужны: Wikidata, датасет рейтингов IMDb, постеры из Википедии или TMDB):

```bash
python3 scripts/pool.py state                        # сводка state.json: закреплено, избранное, убрано, оценки
python3 scripts/pool.py find "Sinners" 2025          # tmdb_id / imdb_id / русское название по Wikidata
python3 scripts/pool.py enrich draft.json pool.json  # id, рейтинг IMDb, жанры, режиссёр, награды, is_new, постер
python3 scripts/pool.py validate pool.json           # 30–40 фильмов, пороги, квота новинок, ничего из убранного
python3 scripts/pool.py publish pool.json --push     # movies.json + history.json + posters/, коммит и push
python3 scripts/pool.py taste                        # taste.json — счётчики вкусов по оценкам Насти
```

Черновику достаточно `title`, `original_title`, `year`, `note` — остальное дописывает `enrich`; поля фильмов, уже лежащих
в `movies.json`, сохраняются. Необязательные ключи `OMDB_KEY` и `KINOPOISK_KEY` в `~/.config/nastya-home/keys.env`
добавляют Metacritic/Rotten Tomatoes и рейтинг Кинопоиска. `history.json` хранит всё, что когда-либо показывали, со статусами
(`shown`, `rotated`, `watched`, `skip`) и оценками — такие фильмы больше не предлагаются. Старый `scripts/publish.py` (ровно десять
фильмов) оставлен для совместимости.

## Сборка и установка

```bash
./gradlew assembleRelease
~/Library/Android/sdk/platform-tools/adb connect 192.168.1.121:5555
~/Library/Android/sdk/platform-tools/adb -s 192.168.1.121:5555 install -r app/build/outputs/apk/release/app-release.apk
```

Домашним экраном приложение назначается через LauncherHijack (выбрать «Дом Насти» в его списке).
Сброс кэша и меток: `adb shell pm clear ru.nastya.home` (только с разрешения — см. CLAUDE.md).
Отправка `state.json` в репозиторий включается токеном GitHub: fine-grained PAT с правом Contents: Read and write только на этот
репозиторий, строка `github.token=github_pat_…` в `local.properties` (файл в `.gitignore`), затем пересборка. Без токена всё
работает локально на проекторе.

### Проверка сети с самого проектора

На проекторе нет curl, поэтому в приложении есть служебный пробник (пишет в logcat, тег `NastyaProbe`):

```bash
adb shell "am start -n ru.nastya.home/.ProbeActivity --es urls 'https://a|https://b' --es referer 'https://kgd.ru/'"
adb logcat -d -s NastyaProbe
```
